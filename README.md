# Links Hub

A lightweight, mobile-friendly landing page designed to route visitors to my portfolio, GitHub, and LinkedIn from a single link or QR code.

## 🚀 Features

- **Responsive Design:** Styled with standard CSS and system fonts for fast loading on mobile and desktop.
- **Zero Dependencies:** Pure HTML and CSS—no frameworks or build steps required.
- **Dark Mode Aesthetic:** Built with a dark palette out of the box.
